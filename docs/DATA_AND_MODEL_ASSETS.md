# 数据、知识与模型资产

PowerAnalytics 源码与运行资产分离。公开源码不附带能够复现演示环境全部业务数据、模型推理、RAG 文档和向量索引的资产包。

## 资产矩阵

| 资产 | 公开仓库 | 获取/生成方式 | 关键约束 |
|---|---|---|---|
| PostgreSQL Schema | 提供 Alembic 迁移 | 在获授权数据库执行迁移 | 先备份；使用迁移身份；禁止无检查点升级 |
| 演示业务数据 | 不默认提供 | 按真实字段、约束和计算规则自备或受控生成 | 必须保留来源、批次、场景和生成时间；不得冒充实时采集 |
| 预测特征输入 | 不提供历史业务文件 | 按 170 特征契约构建 | 必须是连续 24 小时、列顺序/类型/时区/Schema 一致 |
| 预测模型二进制 | 不提供 | 使用自有训练资产或受许可模型 | 反序列化前核对 hash、来源、运行时和隔离环境 |
| 模型元数据 | 可提供非敏感 Schema/示例 | 由模型治理流程生成 | Candidate 不得自动晋升 Active |
| 原始知识文档 | 不提供 | 使用自有或明确获授权的文档 | 公开可访问不等于可再分发 |
| Chunk / Embedding | 不提供 | 从获授权文档本地生成 | 保留文档、Chunk、模型与版本的可追溯关系 |
| Qdrant Collection/Snapshot | 不提供 | 在本机导入、校验并发布 | Collection/Alias、维度、模型与 PostgreSQL Release 必须一致 |
| BGE / Reranker 权重 | 不提供 | 从原作者或模型平台按其许可证获取 | 包许可证与模型权重许可证分别核验 |
| 云端 LLM Key | 永不提供 | 用户在本机秘密系统中配置 | 先完成数据分类、脱敏和供应商条款审查 |
| 产品截图 | 提供作者自有截图 | 从本项目真实录屏母带提取 | 用于项目展示并随仓库按 AGPL-3.0-or-later 分发；作者已确认权利，不含登录、桌面、错误页或秘密 |
| 演示视频 | 当前不提供 | 仅在专业精剪成片完成后作为 Release Asset | 不上传原始母带或失败片段 |

## 预测资产准入

模型 Artifact 不能只凭文件存在进入运行态。最低需要：

1. 来源和所有权记录；
2. 文件 hash 与不可变 Manifest；
3. Python、scikit-learn、LightGBM/XGBoost 等运行时版本；
4. 170 个有序特征、dtype、时区和 Schema hash；
5. 评测指标与数据泄漏门禁；
6. Candidate 状态与人工确认；
7. 明确回滚目标。

未经授权不要加载未知 Pickle/Joblib 文件。

## 知识资产准入

每份拟导入文档至少记录：

- 标题、作者/权利人、来源和取得日期；
- 许可证或书面授权，以及复制、修改、检索、商用和再分发范围；
- 数据分类、个人信息、商业秘密和客户限制；
- 内容 hash、解析器版本、Chunk 策略和 Embedding 模型；
- 发布版本、Qdrant Collection/Alias 和回滚信息；
- 删除请求、法律保留和派生资产处置方式。

如果无法证明证据，回答应为“证据不足”，而不是生成一个看似合理的 Citation。

## 最小本地能力

在没有外部模型、知识文档和模型权重时，可以先验证：

- 前后端构建；
- PostgreSQL Schema 与权限；
- 健康接口和基础页面；
- API 的 Loading、Empty、Error、Unauthorized 与 Forbidden 状态；
- 预测/模型/RAG 对缺失资产的失败关闭行为。

AI、RAG 和预测完整演示需要用户自行提供合法、兼容并经过准入的资产。配置方式见 [快速开始](QUICKSTART.md)，处理链见 [系统架构](ARCHITECTURE.md)。
