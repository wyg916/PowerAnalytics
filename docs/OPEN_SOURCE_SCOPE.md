# PowerAnalytics 开源范围

本文定义 `v2.12.1-open-source` 首个公开快照的边界。目标仓库 `wyg916/PowerAnalytics` 在发布前为空，因此公开版本从干净目录创建首个提交，不继承内部仓库的 Git 历史、审计证据和本机运行资产。

## 已公开范围

- Web 前端源码：React、TypeScript、Vite、Ant Design 与 ECharts。
- FastAPI 后端源码：API、领域 Service、Repository、认证/RBAC、AI 编排与安全控制。
- 预测与模型治理源码：特征、契约、训练/推理辅助、Candidate/Active 准入与回滚设计。
- RAG/Memory/Trace 的通用工程源码，不含语料、向量、权重和本机发布事实。
- PostgreSQL Alembic 迁移与非敏感示例配置。
- 自包含测试，以及作者确认可公开、无个人或客户数据的 ChatBI Golden 50 评测夹具。
- README、架构、快速开始、演示、安全、贡献与第三方边界文档。
- 作者自有的品牌图，以及通过出站核验、确认不含未授权第三方内容或敏感身份信息的真实产品截图。
- 作为 GitHub 原生视频附件与 Release Asset 单独分发、通过出站核验并记录哈希的最终精剪项目宣传片；不纳入 Git 历史。

## 为什么使用干净快照

仅在工作树中删除文件不能从 Git 历史移除内容。内部仓库历史包含知识材料、验收证据和大资产；把该历史推到新的公开仓库可能泄露已经删除的内容。因此首个公开快照执行了：

1. 从空目录按精确 allowlist 复制公开文件；
2. 不复制内部 `.git`、Worktree 指针或任何历史对象；
3. 在快照根重新执行秘密、绝对路径和大文件扫描；
4. 对依赖、许可证、语料与媒体权属做出站审查；
5. 在目标空仓库创建全新的首个提交。

## 许可证与权利结论

- PowerAnalytics 自有源码、文档、品牌图和产品截图采用 AGPL-3.0-or-later。
- 作者已于 2026-08-30 确认仓库内第一方项目内容、截图和 Golden 50 评测夹具可以公开发布。
- PyMuPDF/MuPDF 按 AGPL 路径使用；其自身许可证不被根项目许可证替代。
- PySide6、PySide6-Fluent-Widgets、模型权重、原始语料及派生索引均未进入公开快照。
- 第三方组件和用户自行导入的资产继续按各自许可证或条款授权，详见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 每次发布门禁

公开推送前必须同时满足：

- 根许可证与实际依赖、捆绑内容兼容；
- PyMuPDF 等多许可证/强 Copyleft 依赖完成明确选择与义务评估；
- 原始语料及其派生产物有可证明的处理和再分发权，或全部从快照排除；
- 所有本机用户绝对路径、真实秘密和内部运行配置已排除或参数化；测试中仅保留明确的合成凭据夹具，不作为任何运行环境凭据；
- 源码、迁移、前端 build、定向测试、Markdown/JSON/链接检查通过；
- 首个公开提交完成秘密扫描与 tracked large-file 扫描；
- Release、徽章、Tag、README 数字和 GitHub 元数据与最终 SHA 一致。

后续 Release 若新增依赖、模型、字体、图标、图片或语料，必须重新完成相应权利和许可证核验；未闭环的新增资产不得进入分发物。
