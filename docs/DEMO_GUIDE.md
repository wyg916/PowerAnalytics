# PowerAnalytics 演示指南

本指南用于本地产品演示、技术交流和面试讲解。截图与示例基于历史回放环境，不代表实时电力市场、真实交易执行或生产运行。

## 推荐路线（12–18 分钟）

1. **总览驾驶舱（1 分钟）**：从风险窗口、预测概览、策略、任务与数据健康建立全局认识。
2. **24 小时预测（2 分钟）**：展示连续 24 小时曲线、峰谷时段、置信度与小时明细。
3. **峰谷分析（1 分钟）**：解释最高/最低电价、峰谷价差、评估与特征门禁。
4. **策略证据（2 分钟）**：从预测事实进入策略与人工复核，强调“建议而非自动执行”。
5. **AI 短期记忆（2 分钟）**：验证同一会话内的风险偏好、重点时段和回答顺序。
6. **跨会话长期记忆（2 分钟）**：新 Session 不重复输入偏好，召回已有且真实保存的内容。
7. **RAG + Citation（2 分钟）**：从知识库检索简单事实，展开 Citation 核对证据。
8. **知识库（1 分钟）**：展示文档、Chunk、索引和发布状态，不展示无权公开的原文。
9. **模型中心（1 分钟）**：展示 Active/Candidate、指标、准入门禁和回滚边界。

### 3. 峰谷分析与模型评估

![峰谷分析](media/screenshots/forecast-analysis.webp)

- 展示峰值、谷值、价差、回测与泄漏门禁。
- 指标服务于风险研判，不构成交易收益承诺。

### 4. 策略证据与人工复核

![策略证据](media/screenshots/strategy-evidence.webp)

- 策略建议必须指向预测依据与运行事实。
- 风险等级和复核状态不会自动触发交易、资金或设备动作。

## AI 演示脚本

### 5. 短期记忆

在一个**全新会话**中依次输入：

```text
请记住本轮分析的三个约束：
1. 风险偏好：稳健；
2. 重点时段：18:00—21:00；
3. 回答方式：先给结论，再给依据。
请只复述这三个约束。
```

然后输入：

```text
按照刚才的要求，分析最新一轮24小时预测中需要重点关注的时段，并给出建议。
```

最后输入：

```text
不要重新分析。
只告诉我：
1. 我刚才要求的风险偏好是什么？
2. 我重点关注哪个时段？
3. 我要求你按照什么顺序回答？
```

通过标准：正确返回“稳健”“18:00—21:00”“先结论再依据”，且没有把证据不足的价格或天气数值补造出来。

![AI 短期记忆](media/screenshots/ai-short-memory.webp)

### 6. 跨会话长期记忆

创建 Session A，不在 Prompt 中重新提供历史偏好：

```text
你还记得我以前保存过的分析偏好吗？
请只列出你能够真实召回的内容。
不知道的不要补充。
```

再创建完全新的 Session B：

```text
按照你记得的我的分析偏好，为“电价风险简报”设计一个输出结构。
同时先说明你使用了哪些历史偏好。
```

通过标准：Session B 是新会话，Prompt 没有重新输入偏好，回答至少使用一项真实召回的历史偏好，且不补造不存在的记忆。

![AI 跨会话长期记忆](media/screenshots/ai-long-memory.webp)

### 7. RAG + Citation

先在知识库选择一份权利明确、内容简单、页面正常的文档，并从真实 Chunk 构造单一事实问题：

```text
仅依据当前知识库回答：
该文档中规定的目标事实是什么？

只输出：
1. 答案
2. 引用来源

如果知识库没有明确证据，请直接回答“证据不足”。
```

通过标准：检索到真实证据、答案与证据一致、Citation 能展开并核对来源。不要用复杂多政策比较，也不要伪造引用。

![RAG Citation](media/screenshots/rag-citation.webp)

## 8. 知识库

![知识库](media/screenshots/knowledge-base.webp)

- 说明 Document → Chunk → Embedding → Qdrant → Reranker → Citation 链路。
- 数量会随环境变化；公开介绍使用 `80+ documents`、`8k+ knowledge chunks` 的稳定口径。
- 原始文档、Chunk 和向量资产不随公开源码提供。

## 9. 模型中心

![模型中心](media/screenshots/model-center.webp)

- Active 与 Candidate 分离；指标、特征契约和训练事实可追踪。
- Candidate 未通过准入和人工确认不得晋升；回滚同样需要明确目标与确认。

## 演示边界

- 不展示真实密码、API Key、数据库连接、个人信息、客户数据或未获授权的文档正文。
- 不执行自动交易、资金操作、设备控制、模型自动晋升或 RAG 自动发布。
- 外部 LLM、Qdrant 或数据库不可用时，保留真实 Error/Unavailable 状态，不用静态成功态替代。
- 若 Citation 无法生成，可退回展示真实 Knowledge Search → Result → Document → Evidence；不能伪造 Citation。
